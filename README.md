# 🚀 Desafios Diários – Exercism

Este repositório contém meus exercícios resolvidos diariamente na plataforma Exercism.

O objetivo é praticar programação todos os dias, melhorar minhas habilidades de lógica, aprender boas práticas e evoluir constantemente como desenvolvedor.

---

## 📚 Sobre o Exercism

O Exercism é uma plataforma gratuita que oferece exercícios de programação em diversas linguagens, com foco em:

- prática constante

- feedback da comunidade

- aprendizado progressivo

- resolução de problemas reais

🔗 Plataforma: https://exercism.org/
